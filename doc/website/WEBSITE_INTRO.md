## 3. 每图介绍文案

### 01 首页 —— 「打开即片场」

短版：综合、猜你喜欢、热门、新片、高分五种信息流，一个入口看遍所有片源。看到一半的内容会出现在续播条上，一触即回上次进度。

长版：Jive 的首页为夜间观影而生——「夜幕影院」深色主题，柔和的琥珀色点缀，海报墙在暗色下格外沉浸。顶部一键切换片源，综合流按分类持续更新，「猜你喜欢」由 AI 推荐并自动在片源中匹配可播版本，热门/新片/高分来自 TMDB 榜单策展。看到一半退出？续播条会带着你的进度在原地等你。

### 02 详情 —— 「一部片，多个源」

短版：播放、追更、片头片尾跳过，一屏搞定。当前源资源不佳？「查找其他来源」自动探测全部片源，选中即可无缝换源。

长版：详情页聚合了关于这部片的全部决策信息：地区、年份、分类、更新到第几集、主演阵容。支持追更的内容一键开启更新提醒；片头/片尾跳过按你的习惯记忆。多个片源同时收录时，Jive 会逐源探测资源并标注集数状态，跨源也绝不错过。

### 03 播放器 —— 「越看越顺滑」

短版：边下边播、自动跳过片头，进度条、倍速、选集、手势全都在拇指可及之处。播放状态一枚圆点轻声告知，不打扰你的电影。

长版：Jive 的播放器深谙本地播放之道：HLS 分片边下边播，越往后越流畅；自动识别并剔除视频流中的广告分片，时间轴无缝衔接。竖屏窗口与全屏沉浸两种形态自由切换，手势调节亮度音量、长按倍速、滑屏快进——所有控制都在拇指可及之处。播放健康状态由一枚小圆点静静指示，长按还可查看详情。

### 04 我的 —— 「你的观影足迹」

短版：追更的、收藏的、看过的，各归其位。追更内容有新集，红点与徽标第一时间告诉你；下载与片源管理也在这一个页面。

长版：「我的」页是你的观影中枢：追更列表带着「更新至 N 集」徽标，有新集立即提醒；收藏随时回看；最近观看记录每次进度，点开即续播。下载管理、片源测速与播放设置也都在这里，一页掌控全局。

## 4. 功能亮点短句（官网可复用）

- **多源聚合**：一个 App 看遍多个片源，全局切源、跨源搜索、详情页一键换源。
- **边下边播**：分片级缓存 + 本地代理，看过的部分随时离线重放，越看越流畅。
- **广告过滤**：自动识别视频流中的广告分片并剔除，时间轴无缝重映射。
- **续播与追更**：进度永远同步，追更内容有新集即刻提醒。
- **离线下载**：整季下载，默认仅 Wi-Fi，出差路上随便看。
- **夜幕影院**：专为夜间观影打磨的深色主题，iPhone、Android、平板一致体验。

> 文案口径以 [../flows/](../flows/) 盘点的实际功能为准，勿放大：投屏尚未实现；「猜你喜欢」依赖后端推荐服务；TV 适配开发中。

## 5. 截图重新生成方式

截图由 `integration_test/screenshot_tour_test.dart` 驱动真实应用产生（深色模式下按「详情 → 播放器 → 首页续播 → 我的」流程导航），步骤：

```bash
xcrun simctl ui booted appearance dark        # 模拟器切深色（夜幕影院主题）
# 终端 A：高频截帧
while true; do xcrun simctl io booted screenshot /tmp/jive_frames/f_$(printf '%04d' $i).png; sleep 1.2; done
# 终端 B：运行巡检（构建 + 启动 + 自动导航，约 1.5 分钟）
fvm flutter test integration_test/screenshot_tour_test.dart -d <simulator-udid>
```

测试会输出带时间戳的 `TOUR_STAGE:<name>` 标记（detail / player / home / profile），按标记区间从帧中挑取最佳帧。注意：`flutter test` 结束后会卸载应用，数据不跨轮保留，因此巡检把「播放」排在首页截图之前，让续播条与追更卡片在同一会话内出现。
