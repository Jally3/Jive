## 新发现

### 1. 视频纹理层存在稳定性风险

完整播放器有可见画面并持续推进，但一次 6308 行的 HiLog 采样中出现 224 次以下错误：

```text
OH_NativeImage_AcquireNativeWindowBuffer() failed or buffer is null, ret = 40601000
```

错误来自 Flutter OpenHarmony 外部纹理层。当前没有造成持续黑屏或崩溃，但可能与第一阶段偶发的横屏黑画面有关。进入发布适配前，需要在 API 26 环境和真机上观察错误频率，并确认长时间播放、频繁旋转和前后台切换后是否出现丢帧或黑屏。

### 2. 调试包必须保持签名一致

模拟器保留旧应用数据时，unsigned HAP 安装返回 `install sign info inconsistent`。使用工程现有调试签名构建后可以覆盖安装并保留数据。日常设备验证应统一使用：

```bash
./tool/build_ohos.sh --debug --signed
```

`ohos/build-profile.json5` 中只保留无签名的通用配置。DevEco Studio 生成的本机调试证书路径和口令不能进入版本库。

### 3. 根目录 HAP 会被验证入口覆盖

完整应用和 `tool/ohos_phase1/main.dart` 共用 `build/ohos/hap/entry-default-signed.hap`。切换 `--target` 后产物会被覆盖。本轮结束时已重新构建、安装并启动完整 Jive 入口。
