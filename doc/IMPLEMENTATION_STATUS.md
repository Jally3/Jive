# Jive V1 实现状态

依据 `APP_REQUIREMENTS_V1.md`，当前移动端 MVP 已实现以下功能：

- 首页：最新内容 + 全部分类 Chip 同页切换过滤、下拉刷新、去重分页加载、封面/名称/类型/更新状态；分类加载失败可独立重试，不阻塞内容网格。
- 搜索：400ms 防抖、旧请求隔离、清空、分页、空结果和失败重试。
- 详情：封面、名称、简介、类型、更新时间、状态、展开简介；详情元数据不保留播放 URL；支持收藏/取消收藏。
- 播放：仅在点击播放/剧集时解析最新地址，支持 HLS/MP4、暂停、拖动、自动隐藏控制层、全屏、横竖屏；初始化失败或播放中断均可重新解析地址后重试。
- 我的：收藏（本地快照，不含播放地址）与最近观看合并为一个入口；最近观看本地保存视频、剧集、播放位置、总时长及完成状态，每 5 秒、暂停及退出时串行保存，支持续播、已播完从头播放和清空。
- 稳定性：12 秒 API 超时、异常 JSON/字段容错、HTTPS 播放地址过滤、详情短时缓存、播放器资源释放。

## Android 模拟器实测（API 35 / ARM64）

- APK 流式安装成功，冷启动 `Status: ok`，启动耗时约 2.1 秒。
- 首页成功显示真实 VOD 内容和远程封面，分类入口及底部导航可访问。
- 首页演示卡片可进入详情，详情展示简介、状态和剧集。
- 点击播放后 AndroidX Media3 ExoPlayer 初始化成功，H.264 视频与音频解码器均创建，视频画面实际渲染。
- 播放约 4 秒退出后，最近观看页面显示对应视频、剧集、进度条与 `0:04` 进度。
- 最新主题复验确认当前导航选中态和主要操作统一使用琥珀色 Token。

- Android 真实第三方 HLS、后台切换和横竖屏；iPhone 的真实 HLS、后台切换和横竖屏。
