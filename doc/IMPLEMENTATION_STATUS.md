# Jive V1 实现状态

依据 `APP_REQUIREMENTS_V1.md` 与 `VOD_SOURCE_SWITCH_PRD_AND_PLAN.md`，当前移动端 MVP 已实现以下功能：

- 首页：最新内容 + 全部分类 Chip 同页切换过滤、下拉刷新、去重分页加载、封面/名称/类型/更新状态；分类加载失败可独立重试，不阻塞内容网格；标题区右上角显示当前内容源并可切换全局源，切源后首页分类与列表重建。
- 搜索：600ms 防抖、旧请求隔离（generation）、清空、分页、空结果和失败重试；1 个当前源 + 最多 3 个备用源自动探测（关键词 ≥ 2 字符），来源标签展示准确数量/估算数量/失败状态；点击备用来源只切换当前搜索页来源，不修改全局源；"更多"弹窗默认只读，未搜索源按需请求，底部提供显式"检测全部来源"；按源独立分页、查询缓存（约 7 分钟）和并发上限 2。
- 详情：封面、名称、简介、类型、更新时间、状态、展开简介；详情元数据不保留播放 URL；支持收藏/取消收藏；详情页默认只请求当前视频所属源，不自动探测备用源；点击"检测其他来源"后并发探测最多 3 个备用源，来源标签区分"剧集数/有资源/未检测/失败"；跨源候选需用户确认后原子切换，保留当前选集（无法匹配时提示回到第一集），不修改全局源；"更多"弹窗按需请求，"检测全部来源"显式触发。
- 播放：仅在点击播放/剧集时解析最新地址，支持 HLS/MP4、暂停、拖动、自动隐藏控制层、全屏、横竖屏；初始化失败或播放中断均按当前视频所属源重新解析地址后重试；播放器重试绑定实际播放资源（VideoRef）。
- 我的：收藏（本地快照，不含播放地址）与最近观看合并为一个入口；内容源入口可查看/切换全局源；最近观看本地保存视频、剧集、播放位置、总时长及完成状态，每 5 秒、暂停及退出时串行保存，支持续播、已播完从头播放和清空；历史续播按记录来源刷新地址。
- 多源架构：`VodSourceRegistry` + `VodSourceAdapter`（Mac CMS V10）按源发起请求；Repository 方法接收 `VodSource`/`VideoRef`，不依赖可变全局 `baseUrl`；详情缓存键使用 `globalId`。
- 资源身份：`Video` 带 `sourceId`/`sourceVideoId`/`globalId`、`year`/`area`/`actors`/`director` 匹配字段；`VideoRef`、`PlaybackLine` 模型；旧数据缺 `sourceId` 默认迁移为 `storm`；收藏/历史/Widget Key 均按 `globalId` 去重。
- 稳定性：12 秒 API 超时、异常 JSON/字段容错、HTTPS 播放地址过滤、详情短时缓存、播放器资源释放。

## Android 模拟器实测（API 35 / ARM64）

- APK 流式安装成功，冷启动 `Status: ok`，启动耗时约 2.1 秒。
- 首页成功显示真实 VOD 内容和远程封面，分类入口及底部导航可访问。
- 首页演示卡片可进入详情，详情展示简介、状态和剧集。
- 点击播放后 AndroidX Media3 ExoPlayer 初始化成功，H.264 视频与音频解码器均创建，视频画面实际渲染。
- 播放约 4 秒退出后，最近观看页面显示对应视频、剧集、进度条与 `0:04` 进度。
- 最新主题复验确认当前导航选中态和主要操作统一使用琥珀色 Token。
