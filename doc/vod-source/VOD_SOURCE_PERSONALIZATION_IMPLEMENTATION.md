## 接口约定

- `VodSourceCustomizations` 保存按 sourceId 索引的个人设置，以及互斥的有序置顶/置底 ID；来源本身不变。
- `vodSourceCustomizationsProvider` 提供初始化及 save / togglePinned / toggleDemoted / reset 操作；持久化成功后发布状态，失败可重试。
- `VodSourcePresentation` 组合原源和个人设置，统一排序筛选，供管理页与弹层使用。
- 私人标签不改变自动检索优先级、不触发切源、不绑定源分类。
