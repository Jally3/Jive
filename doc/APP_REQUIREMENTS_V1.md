# 视频 App 第一版需求文档

## 1. 项目概述

本项目是一款基于 Flutter 开发的视频点播 App。第一版通过 VOD API 获取视频元数据和播放地址，为用户提供视频浏览、搜索、详情查看和在线播放功能。

当前计划接入的测试数据源：

```text
https://bfzyapi.com/api.php/provide/vod
```

> 正式上线前，必须确认视频内容、API 数据及播放地址具备合法授权，并确认符合目标平台的审核要求。

## 2. 第一版目标

完成一个可以在 Android 和 iOS 真机运行的 MVP，用户能够：

1. 查看视频列表
2. 按分类浏览视频
3. 搜索视频
4. 查看视频详情
5. 播放电影或剧集
6. 切换全屏、暂停、拖动进度
7. 记录最近观看内容

## 3. 目标平台

- Flutter
- Android 手机
- iOS 手机
- 第一版暂不支持 Web、桌面端和电视端

## 4. 功能范围

### 4.1 首页

- 展示视频分类入口
- 展示最新或推荐视频列表
- 支持下拉刷新
- 支持分页加载
- 视频卡片显示封面、名称、类型和更新状态

### 4.2 分类页

- 展示视频分类
- 按分类加载视频
- 支持分页加载
- 支持加载中、空数据和加载失败状态

### 4.3 搜索

- 输入关键词搜索视频
- 展示搜索结果
- 支持清空关键词
- 支持无结果状态
- 搜索请求需要防止频繁重复调用

### 4.4 视频详情

- 展示封面、名称、简介、类型、更新时间和状态
- 展示剧集列表
- 支持选择剧集播放
- 记录当前观看剧集
- 播放地址只在用户点击播放时请求

### 4.5 播放器

- 播放 HLS 或其他已验证的 VOD 播放格式
- 播放、暂停
- 进度拖动
- 全屏播放
- 横竖屏切换
- 播放失败提示和重试
- 显示当前播放剧集
- 播放页销毁时正确释放播放器资源

第一版暂不实现下载、投屏、倍速、字幕切换和 DRM，除非实际 VOD 源验证后明确需要。

### 4.6 最近观看

- 保存最近观看的视频
- 保存最近观看的剧集
- 保存播放进度
- 支持从最近观看继续播放
- 第一版可先使用本地存储，不做多设备同步

## 5. VOD 接口约定

### 5.1 测试接口

```text
列表：
GET https://bfzyapi.com/api.php/provide/vod/?ac=list&pg=1

详情：
GET https://bfzyapi.com/api.php/provide/vod/?ac=detail&ids={vod_id}

搜索：
GET https://bfzyapi.com/api.php/provide/vod/?ac=list&wd={keyword}&pg=1

分类：
GET https://bfzyapi.com/api.php/provide/vod/?ac=list&t={type_id}&pg=1
```

### 5.2 需要解析的主要字段

- `vod_id`：视频 ID
- `vod_name`：视频名称
- `vod_pic`：封面地址
- `type_id`：分类 ID
- `type_name`：分类名称
- `vod_remarks`：更新状态或集数信息
- `vod_content`：视频简介
- `vod_play_from`：播放源名称
- `vod_play_url`：剧集名称与实际播放地址

### 5.3 接入原则

- Flutter 不直接保存任何源站密钥
- 正式环境建议增加自己的后端 API
- 对外只返回经过权限校验的播放地址
- 播放地址可能过期，需要支持重新获取
- 所有请求使用 HTTPS
- 对接口返回值做字段缺失和格式异常处理

## 6. 页面结构

```text
启动页
  └── 首页
       ├── 分类页
       ├── 搜索页
       ├── 视频详情页
       │    └── 播放页
       └── 最近观看页
```

## 7. 非功能需求

### 性能

- 列表采用分页加载
- 图片使用缓存
- 避免重复请求同一详情
- 播放器页面退出后释放资源
- 弱网下显示明确的加载和错误状态

### 稳定性

- 网络超时可重试
- API 返回异常时不能导致 App 崩溃
- 播放地址失效时允许重新获取
- 处理无封面、无简介、无剧集等异常数据

### 安全与合规

- 仅使用拥有合法授权的视频内容和播放源
- 防止播放地址和接口密钥被不必要地暴露
- 准备隐私政策和用户协议
- 上线前检查 App Store 和 Google Play 的内容政策

## 8. 第一版验收标准

- Android 和 iOS 真机均可启动
- 首页能成功加载视频列表
- 分类筛选结果正确
- 搜索结果与关键词相关
- 详情页能展示基本信息
- 至少一个真实视频可以正常播放
- 播放器支持暂停、拖动进度和全屏
- 播放失败时有提示和重试入口
- 能保存并展示最近观看记录
- API 断网、超时、空数据和错误响应不会导致崩溃
- 连续打开和关闭播放页后无明显卡顿或内存问题

## 9. 暂不开发

- 用户注册、登录和会员体系
- 支付和订阅
- 评论、点赞和分享
- 个性化推荐
- 视频下载
- DRM 加密播放
- Chromecast、AirPlay 和其他投屏
- 多设备播放进度同步
- 后台运营管理系统
- 广告系统

## 10. 开发阶段

### 阶段一：播放能力验证

- 验证真实详情接口
- 解析 `vod_play_url`
- 获取真实 `.m3u8` 或其他播放地址
- 在 Android 和 iOS 真机播放

### 阶段二：基础页面

- 搭建首页、分类、搜索、详情和播放页
- 完成统一的加载、空数据和错误状态

### 阶段三：本地能力

- 增加最近观看
- 保存播放进度
- 增加缓存和请求去重

### 阶段四：质量验证

- 测试弱网、断网和过期播放地址
- 测试横竖屏和后台切换
- 测试不同尺寸视频和异常接口数据
- 进行 Android 和 iOS 打包测试

## 11. 待确认事项

- 视频源是否拥有明确授权
- API 是否稳定、是否有调用频率限制
- `vod_play_url` 的实际字段格式
- 播放地址是否需要 Referer、Token 或特殊 Header
- 是否需要自建后端代理
- 首发地区和目标应用商店
- 是否需要登录、会员或付费功能
- App 名称、Logo、主题色和视觉风格
