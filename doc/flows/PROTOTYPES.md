# 页面原型图集（ASCII 线框）

状态：持续生效（基于 v1.1.0+5）
相关文档：[README.md](README.md)、[NAVIGATION_MAP.md](NAVIGATION_MAP.md)、[../design/DESIGN_SYSTEM.md](../design/DESIGN_SYSTEM.md)

## 1. 阅读说明

- 本文为**低保真线框**，记录每个页面的区块构成与交互点，供改版盘点；具体颜色/字号/圆角/间距 Token 以 `DESIGN_SYSTEM.md` 为准（本文以「⟨token⟩」标注关键引用）。
- 线框按手机竖屏（约 390×844）绘制；宽屏差异统一见第 14 节。
- 符号约定：`[ ]` 可点区块、`( )` chip/胶囊、`▾` 弹出菜单、`⋯` 省略内容、`≡` 拖拽手柄。
